# 宋祁专属应用视觉基准

参考用户提供的两张界面图。该方向作为 `feature/songqi-companion` 后续首页与导航改造的正式设计基准。

## 视觉关键词

- 雾粉、粉灰、珍珠白为主，辅以灰紫与少量暖灰；低饱和、低对比，但正文必须保持可读。
- 英文使用优雅衬线字体与克制字距；中文优先宋体/明朝风格，正文保留舒适行高。
- 细线、柔和阴影、轻微纸张/压纹质感；避免厚重毛玻璃、强烈渐变、过多卡片边框。
- 图标使用小型线稿/符号，统一尺寸与视觉重量；入口为圆角方形，图标和英文小标题上下排列。
- 整体是私人纪念册与双人生活空间，不是通用 AI 聊天后台，也不是可爱风社交产品。

## 首页信息架构

1. 顶部品牌区：英文小字标语 + 中文主标题「我们的小窝」。
2. 双人关系主视觉：双方头像并列或相连，展示称呼、关系状态与相处天数。头像必须可由用户设置；未设置时使用优雅占位，不伪造照片。
3. 关系信息：亲密度/关系状态等可选指标，只有真实配置后才显示，避免编造百分比。
4. 今日寄语：独立的短句区域，支持来自用户设置、记忆或 AI 的内容，并能标明来源。
5. 功能入口网格：日记、阅读/收藏、悄悄话、纪念日、问答、想念、周期（可选）、连续记录、记忆、收集、优惠券/约定等。只展示已实现且启用的功能；暂未实现的功能不得做成假按钮。
6. 「我们的收藏」/语录区：空状态提示用户收藏后会在此出现。

## 导航与交互

- 首页是主场景；聊天作为核心入口，保持随时可达，但不要把首页做成聊天列表。
- 参考第二张图的侧边抽屉：展示 Memory、Diary、Whisper、Handover 等次级入口，窄屏优先覆盖式抽屉，不挤压主内容。
- 所有触控目标适合手机，保留 safe-area；抽屉、弹层和键盘出现时不得遮挡标题或输入区。
- 桌面端可以扩展为左右分栏，手机端保持单列主画布与三列入口网格（窄屏可两列）。

## 实施约束

- 本阶段只记录视觉规范，不擅自修改用户头像、关系日期、亲密度、称呼或寄语。
- 首页动态内容必须绑定真实数据；缺少配置时用清晰的空状态/设置引导。
- 复用现有 diary、memory、proactive、music、todo 等功能路由和数据接口，先核验事件处理器，再改 DOM。
- 每一项入口都要能真实打开对应功能；未接通的功能显示「筹备中」或暂不展示。
- 保持现有数据兼容，不改变数据库 schema 作为纯视觉改造的一部分。
