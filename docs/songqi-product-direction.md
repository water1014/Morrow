# 宋祁专属应用：二改方向与源码核验记录

## 产品定位

将 Morrow 改造为单人、私有、自托管的「宋祁」专属 AI 生活空间。保留上游成熟的 Flask + SQLite 服务端、单文件 SPA、PWA、对话、记忆、主动消息、日记、纪念物、音乐和备份能力；逐步把通用家庭应用的身份、信息架构和视觉语言收束为两个人的长期生活空间。

## 约束

- 所有二改只在 `feature/songqi-companion` 分支进行；不直接修改 `main`。
- 保留 MIT 上游许可与版权声明。
- 不删除已有数据结构或破坏数据库兼容；任何 schema 变更必须有幂等迁移与回归测试。
- 不提交真实 API Key、Cookie、数据库、上传内容、备份或个人聊天内容。
- 优先手机端和 PWA；部署仍保持单用户私有空间。
- 先核验调用链，再修改功能；每个阶段运行对应回归测试。

## 源码初审

- 后端入口：`app.py`，Flask 路由、SQLite schema 与迁移集中在此。
- 模型编排：`chat_engine.py`；工具：`tools.py`。
- 前端：`static/index.html` 单文件 SPA，约 0.93 MB；没有独立前端构建步骤。
- 数据：SQLite，运行时目录与凭据必须留在仓库之外。
- PWA：`static/manifest.json`、`static/sw.js`。
- 主动消息：`proactive_engine.py`；图片理解：`vision_engine.py`；语音：`voice_engine.py`；音乐：`music_service.py`。
- 自动化测试：`tests/`，以 Python unittest 为主。

## 分阶段路线

1. **身份与品牌层**：统一应用名、助手默认身份、PWA 元数据和页面文案；随后替换专属图标与启动视觉。
2. **手机端信息架构**：把入口收束为「家 / 聊天 / 记忆 / 共同生活 / 设置」，检查全面屏安全区、键盘、滚动与 PWA 安装态。
3. **宋祁聊天体验**：固定单一伴侣身份，整理人设、上下文、分支、图片理解、语音和模型路由。
4. **记忆殿**：梳理人物外貌、关系设定、事件记忆、长期记忆的读写链路；提供查看、编辑、锁定与删除。
5. **主动陪伴**：核验主动消息调度、频率、安静时段、预算与推送权限，提供可控策略。
6. **共同生活模块**：整合日记、纪念日、待办、音乐、语音信、照片与纪念物。
7. **生图能力**：当前已核实有图片理解/记忆链路，但不能据此认定已有完整文生图；后续单独设计 provider、提示词、参考图、任务状态、取消、图库归档与错误诊断。
8. **备份与部署**：先验证备份/恢复、密钥隔离、手机 PWA；再决定 VPS 与同步方式。

## 第一阶段变更

本阶段只统一可见品牌与默认助手身份，不改数据库 schema、不更改 API 协议、不触碰密钥和用户数据。现有已保存的自定义称呼优先级高于默认值，升级时不会覆盖用户已有身份设置。
